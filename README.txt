أذكاري — ملفات التحديث

ارفع محتويات هذا المجلد كلها إلى جذر مستودع GitHub Azkari (نفس المكان الذي يوجد فيه index.html)، ووافق على استبدال الملفات القديمة. لا ترفع مجلد azkari_update_ready نفسه.

الملفات المطلوبة في جذر المستودع:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- icon-512-maskable.png

بعد Commit changes افتح الموقع على HTTPS وحدّثه تحديثًا قويًا. على Android استخدم Chrome. على iPhone افتح الموقع في Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية. لا يستطيع الموقع فرض التثبيت دون موافقة المستخدم، ونافذة Android الرسمية تظهر فقط عندما يعتبر Chrome الموقع مؤهلًا.

ملاحظة: الإشعار السفلي يختفي نهائيًا على الجهاز بعد الضغط عليه سواء اكتمل التثبيت أم لا، كما يختفي بعد اكتشاف تثبيت التطبيق.
