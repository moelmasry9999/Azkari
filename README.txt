أذكاري PWA v6
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages مع استبدال index.html وmanifest.webmanifest وsw.js.
تأكد أن مجلد icons موجود في الجذر وبداخله ملفات PNG الثلاثة.
بعد الرفع: افتح https://moelmasry9999.github.io/Azkari/ في Chrome، حدّث الصفحة تحديثًا قويًا (Ctrl+Shift+R)، ثم اضغط زر تثبيت أذكاري.
العمل دون إنترنت يبدأ بعد أول زيارة ناجحة واكتمال تخزين ملفات التطبيق.
تنبيهات الشروق والغروب: تعمل أثناء بقاء الصفحة مفتوحة وبعد منح إذن الإشعارات. لا يمكن ضمان وصول إشعار في الخلفية بعد إغلاق Chrome من Service Worker وحده؛ لذلك يلزم Push server أو نسخة تطبيق أصلية بإشعارات محلية مجدولة.
