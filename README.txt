أذكاري - نسخة PWA جاهزة للرفع

مهم: لا ترفع ملف index.html وحده. ارفع كل محتويات هذا المجلد إلى جذر مستودع GitHub Pages (نفس المكان الذي يوجد فيه index.html الحالي) مع الحفاظ على مجلد icons.

يجب أن تكون بنية المستودع هكذا:
index.html
manifest.webmanifest
sw.js
icons/icon-192.png
icons/icon-512.png
icons/icon-512-maskable.png

بعد الرفع:
1) انتظر حتى ينتهي GitHub Pages من النشر.
2) افتح https://moelmasry9999.github.io/Azkari/ في Google Chrome.
3) نفّذ Ctrl+Shift+R لتحديث الملفات، ثم أغلق التبويب وافتحه مرة أخرى إذا استمرت النسخة القديمة.
4) افتح قائمة Chrome ⋮ > Cast, save and share (أو حفظ ومشاركة) > Install page as app (تثبيت الصفحة كتطبيق)، إذا لم يظهر زر التثبيت داخل الموقع.

ملاحظات:
- أيقونة تبويب Chrome مضمنة داخل index.html، فلا تحتاج إلى مجلد للأيقونة الصغيرة.
- أيقونة التطبيق عند التثبيت تأتي من ملفات PNG داخل مجلد icons؛ لا تحذف المجلد أو تغيّر أسماء الملفات.
- زر التثبيت داخل الصفحة يستخدم نافذة Chrome الرسمية عندما يسمح المتصفح بذلك. لا يستطيع الموقع إجبار Chrome على إظهار نافذة التثبيت؛ إذا لم يظهر الحدث، استخدم قائمة Chrome اليدوية أعلاه.
- يجب فتح الموقع عبر HTTPS، ويجب أن تكون ملفات manifest.webmanifest وsw.js وملفات icons متاحة على نفس نطاق الموقع.
- العمل دون إنترنت يبدأ بعد أول زيارة ناجحة واكتمال تخزين ملفات التطبيق.
